# 成片验收

读取原始任务、本轮验收条件和候选成片，独立查看实际视频。主 agent 的实现说明用于定位问题，判定依据来自画面。每条条件都应有可追溯的检查结果；核心条件证据不足时补看相关时段。

## 如何看视频

先覆盖完整时长，确认主体、空间、主要事件和最终状态。按验收条件检查关键近景、接触与释放、遮挡前后、切镜两侧和空间回访。使用 `inspect_video` 或可用的视频查看工具取得画面，给每个结论注明时间或时间区间。快速运动、协调性和瞬间穿插需要密集的连续帧；根据运动速度补查可疑片段。

参考图用于确认要求保持的属性。白模可辅助定位空间与时间问题；最终交付质量以成片为准。修改版本需要检查受影响的片段及其前后衔接，并确认主体与场景整体保持。

## 必须返工

下列问题在实际画面中成立且影响任务要求时，判定需要返工：

- 必需主体、关键对象或主要事件缺失；明确要求的数量、身份、关系或顺序错误。
- 状态变化没有发生、结果不可辨认，或者后续无原因地重置了已经完成的变化。
- 主体在回访或切镜后明显换人、换物，关键环境结构改变，空间关系无法连贯理解。
- 动作中的明显瞬移、严重穿插、肢体异常或接触脱离，破坏主要动作的可读性与协调性。
- 明显违背任务要求的物理关系，导致事件过程或结果错误。
- 持续或占据主要画面的粗糙几何、材质缺失、照明问题、严重模糊或闪烁，使成片明显偏离要求的视觉质量与风格。

每个返工项关联验收条件，说明出现时刻、可见现象和需要恢复的结果。建议修复最直接的责任部分：场景构造、动作、运镜、参考素材或视频提示词。存在多个可能原因时区分观察与推测。

## 可接受的小瑕疵

结合屏幕占比、持续时间、重复程度和对核心事件的影响判断。远景小细节差异、短暂且轻微的接触误差、合理的光照和透视变化，以及任务允许的动作节奏差异，可以记录为轻微问题。

关键身份、任务指定属性或核心因果结果即使只出现一次，也可能需要返工。相同的小瑕疵持续出现或覆盖主要主体时，应重新评估其整体影响。视觉质量与空间、事件正确性均需检查。对已经满足条件的部分保留原结论，返工建议集中于有证据的问题。

## 验收结论

读取 `inputs/criteria.json` 和 `inputs/candidate.mp4`，用 `inspect_video` 选择时间点，并通过 `wait_tool` 接收实际画面。参考图索引位于存在时的 `inputs/references.json`。针对运动、接触和转场连续性，追加密集连续帧进行观察。

调用 `submit_video_acceptance(checks=[...], summary=...)`，每项填写 `id`、`status`、`evidence`、`repair`。`status` 为 `pass`（通过）、`minor`（可接受瑕疵）、`rework`（返工）、`unverified`（证据不足）。`evidence` 写明实际视频时间和可见现象；返工或未验证项填写具体修复或补充检查动作。每条冻结条件都必须覆盖，遗漏的原始任务核心要求可以增加独立检查项。全部项为pass/minor时工具才返回accepted=true。

每轮任务最多返工 3 次。前两次修正后重新验收；第三次拒绝后执行最后一次修正，由主 agent 查看结果并直接 `finish`，后续验收 agent 调用将跳过。修正失败时提交已有的最佳视频。未解决问题写入 `remaining_issues`，交付记录标记返工上限已达到。
