# 生成任务验收条件

收到原始任务后，结合原始需求和实际提供的参考素材，在开始构造前生成本轮验收条件。对每条条件写清任务依据、画面中应出现的结果、检查时段或事件，以及可以接受的偏差。

优先覆盖决定任务成功的主体、关系、事件顺序、最终状态和视觉目标。条件数量随任务复杂度变化；同一要求合并重复检查。避免把自行选择的坐标、建模方式、骨骼数量或镜头参数变成成片标准。白模复杂度由最终可见需求决定。

先判断下列维度是否与本轮任务有关，采用某一维度时按对应指导生成条件。

## 人物外观

选取足以识别同一人物的外观属性：体型轮廓、发型、服装及任务明确要求的特征。跨镜头、遮挡后或回访时应能认出同一人物；合理透视、表情、姿态和光照变化可以接受。用户要求换装或外观变化时注明变化的起点及应保持的属性。

人物近景和承担关键动作的肢体应可辨认，明显的肢体缺失、增生或身份替换属于重点检查。远景细节根据屏幕占比确定要求。验收对象是成片人物；白模中的占位体通过成片身份、位置和事件结果来评估。

## 环境

明确主要空间、关键对象数量、相对位置、通行关系及回访时需要保持的内容。可移动对象和开合等状态按事件阶段检查，已经完成的变化应在后续画面中保持。镜头看到新区域时，应与已建立的空间结构相容。

从用户指定的媒介和风格提取可见的质量要求，如材质区分、结构轮廓、光照层次、前后景密度。视觉质量纳入成片验收；近景关键结构和大面积表面采用更高要求。背景细节变化的容忍度取决于其是否影响场景识别与空间理解。

## 动作连续性与协调性

把动作写成可观察的起始状态、关键过程、结果状态，标明参与者与物件。按任务需要检查持有、接触、支撑、释放关系，以及身体、手部、物件和相机运动之间的配合。

选择接触或分离时刻、遮挡前后、动作衔接处和切镜两侧作为检查位置。自然动作允许节奏和路径的合理变化；要求观众能看清主要事件及其因果顺序。运动平滑性需要查看短时间连续片段，独立静帧仅能支撑外观与状态判断。

## 物理规则

选择任务中实际可见、影响事件结果的规律，如重力方向、惯性、碰撞传播、接触支撑、容纳关系及持续运动趋势。使用定性的可观察关系；用户或 benchmark 明确给出数值关系时保留相应精度。

物件明显悬空、穿过实体、无因消失或运动结果违背任务核心规律应有对应检查。远景接触的小幅偏差按可见程度判断。任务指定的动画风格、幻想设定和刻意夸张应成为规则适用范围的一部分。

## 提交与保持

调用 `set_acceptance_criteria(criteria=[...])`，每条包含 `id`、`category`、`requirement`、`basis`、`check`、`tolerance`，均为非空字符串。`basis` 引用原任务要求或参考依据，`check` 指明观察事件与时段，`tolerance` 描述可接受的轻微偏差。保持稳定标识；本轮条件注册后冻结，返工沿用同一标准。新交互轮次重新生成本轮条件，并保留应延续的状态要求。

主 agent 在构造和渲染中围绕这些条件取证，生成最终视频后调用 `request_video_acceptance(render_uuid=...)`。每轮最多返工 3 次；第三次拒绝后完成最后一次修正并由主 agent 查看，直接提交视频，将剩余问题写入 remaining_issues。
